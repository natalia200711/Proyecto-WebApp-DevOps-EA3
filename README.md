# Proyecto Web App DevOps — Evidencia de Aprendizaje 3 (EA3)

## Introducción
Aplicación web desarrollada en Python con Flask vinculada al caso de estudio de web scraping sobre el producto de Amazon (`ASIN: B0HFMCH32K`), integrando control de versiones en Git/GitHub, pruebas automatizadas con `pytest` y un pipeline CI/CD en GitHub Actions.
